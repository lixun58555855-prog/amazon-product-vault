# 亚马逊商品采集助手 (Amazon Product Collector)

一款专为跨境电商运营、选品研究、数据采集人员打造的 Chrome 浏览器扩展程序（遵循最新 **Google Manifest V3** 标准）。支持在浏览全球任意亚马逊商品详情页时，一键将商品的核心信息（ASIN、标题、高清原图、抓取价格、币种、站点、短链接等）保存至浏览器本地离线数据库中，随时进行多维检索、管理与一键导出。

---

## 🌟 核心特性

- **纯原生前端架构**：采用标准 HTML5、CSS3、现代 JavaScript (ES6+)，开箱即用，**无须复杂的 Node.js 打包与环境编译**。
- **Manifest V3 全面合规**：基于 Service Worker 后台常驻架构与声明式权限规范，运行轻量、高效、省内存。
- **右键上下文菜单一键采集**：在亚马逊商品页任意空白处、文字或图片右键，选择“**📥 添加到本地产品库**”即可秒级入库。
- **智能去重与自动比价更新**：若当前 ASIN 已在库中，系统会自动更新其最新售价与采集时间，并打上更新标记，保留首次采集的历史痕迹。
- **高清原图深度提取**：不仅能获取缩略图，更能自动解析亚马逊 `data-old-hires` 原图地址及 `data-a-dynamic-image` 高清图集矩阵，锁定最高分辨率主图。
- **多站点自适应 & 多级选择器防爬兜底**：全面适配全球各主要亚马逊站点（`.com`, `.co.uk`, `.de`, `.co.jp`, `.fr`, `.ca`, `.in` 等），内置多套价格与标题降级选择器。
- **双工作台界面形态**：
  - **Popup 快捷弹窗**：点击浏览器右上角插件图标，即可快速浏览最近采集的商品、一键采集当前标签页。
  - **全屏独立 Dashboard 面板**：点击“全屏面板”打开专属大屏数据管理中心，支持**网格卡片视图**与**数据表格视图**自由切换。
- **导出与备份保障**：
  - **导出 CSV**：预置 UTF-8 BOM 编码，Windows Excel 直接双击打开**绝无中文乱码**。
  - **JSON 全量备份与导入**：支持跨设备迁移与数据备份恢复。
- **安全与离线可用**：所有数据均存储在浏览器的 `chrome.storage.local` 本地空间中，完全离线运行，断网依然可用，不上传任何第三方服务器，保护商业机密。

## 🚀 Chrome 浏览器本地安装测试步骤

按照以下简单 4 步，即可在本地 Chrome 浏览器中加载并测试本插件：

### 第一步：打开扩展程序管理页面
在 Chrome 浏览器的地址栏中直接输入并回车：
```text
chrome://extensions/
```
或者点击浏览器右上角“三点”菜单 -> **扩展程序** -> **管理扩展程序**。

### 第二步：开启“开发者模式”
在打开的扩展程序管理页面右上角，找到并打开 **“开发者模式”**（Developer mode）的开关切换按钮。

### 第三步：加载已解压的扩展程序
1. 点击页面左上角出现的 **“加载已解压的扩展程序”**（Load unpacked）按钮。
2. 在弹出的文件夹选择框中，选中本项目所在的根目录文件夹：
   ```text
   c:\Users\cc271\Desktop\亚马逊插件项目
   ```
3. 点击“选择文件夹”。此时即可在扩展程序列表中看到 **“亚马逊商品采集助手 - Amazon Product Collector”**。

### 第四步：固定插件图标（推荐）
点击 Chrome 浏览器地址栏右侧的“拼图”形状扩展图标，找到 **“亚马逊商品采集助手”**，点击右侧的 **图钉 📌 按钮**，将其固定到浏览器工具栏，方便随时点击查看！

## 📖 使用指南

### 1. 采集亚马逊商品
1. 打开任意亚马逊商品页面（例如任一商品详情页，形如 `https://www.amazon.com/dp/B08N5WRWNW`）。
2. **方式一（鼠标右键）**：在页面任意空白处、商品标题或图片上点击鼠标右键，在右键菜单中点击 **“📥 添加到本地产品库”**。
3. **方式二（Popup 快捷采集）**：点击右上角插件图标，在弹出的窗口中点击橙色大按钮 **“一键采集当前页面”**。
4. 页面右下角将滑出一个现代质感的悬浮 Toast 提示框，展示采集结果（商品缩略图、ASIN、抓取到的售价及操作状态）。

### 2. 查看与快捷管理 (Popup 弹窗)
- 点击工具栏插件图标，即可查看当前已收录的商品流。
- 支持按标题或 ASIN 实时关键词检索。
- 点击卡片标题直接在浏览器新标签页打开该商品的亚马逊规范短链接。
- 点击垃圾桶图标即可删除当前商品。

### 3. 全功能产品库工作台 (Dashboard)
- 在 Popup 弹窗中点击右上角 **“全屏面板”** 按钮，系统将在新标签页中打开独立的本地产品库管理系统。
- **多维指标**：实时统计商品总数、覆盖的全球站点数、最新入库时间。
- **视图切换**：
  - 🖼️ **网格卡片视图**：适合视觉化选品与图片对比。
  - 📊 **表格视图**：适合运营人员快速对比价格、ASIN 和多站点信息。
- **快捷复制**：鼠标点击卡片或表格中的 ASIN 标签，即可自动将 ASIN 复制至剪贴板；点击链接图标可一键复制无跟踪参数的规范商品短链接。
- **离线导出**：
  - 点击 **“导出 CSV (Excel)”**，一键生成结构化报表。
  - 点击 **“备份 JSON”** / **“导入 JSON”**，轻松实现跨电脑数据迁移备份。

## ⚙️ 核心数据提取逻辑与容错机制

| 提取字段 | 提取优先级与容错策略 |
| :--- | :--- |
| **ASIN** | 1. 正则匹配 URL 路径中 `/dp/`、`/gp/product/` 后的 10 位特征码；<br>2. 备选页面 `#ASIN`、`input[name="ASIN"]` 隐藏域；<br>3. 备选 `[data-asin]` 属性容器。 |
| **商品标题** | 依次尝试 `#productTitle`、`#title`、`#ebooksProductTitle`、`meta[property="og:title"]`、`h1`，并自动清洗首尾多余换行与连续空格。 |
| **高清原图** | 优先提取 `data-old-hires` 高清属性；若无则自动解析 `data-a-dynamic-image` JSON 矩阵计算面积最大的超清图片 URL；降级采用 `src` 或 `og:image`。 |
| **售价** | 适配最新的隐藏可访问性文本 `.a-price .a-offscreen`、`#priceblock_ourprice`、`#corePriceDisplay_desktop_feature_div` 等，备选整数组合。 |
| **币种与站点** | 从页面 Hostname 解析国家站点（如 `.com`、`.co.jp`），结合价格符号（`$`、`£`、`€`、`¥`）智能识别币种。 |
| **持久化规范** | 写入 `chrome.storage.local`，以 ASIN 为唯一主键进行判断，若存在则更新价格与时间，若不存在则追加至顶部。 |
